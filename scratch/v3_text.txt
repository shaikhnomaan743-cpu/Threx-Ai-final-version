##### SLIDE 3 #####
 2: Technical Approach
 4: SIH26145  ·  NTRO  ·  Caffeinated Coders
 5: Six detectors, one per PS threat category (a)-(f). Each reads only features a one-way tap can actually see.
 7: Technologies used
 8: Languages  Python 3.11, TypeScript || Backend  FastAPI, asyncio, Uvicorn, WebSocket || Capture  Scapy (sniff-only), NetFlow/IPFIX parser || ML  scikit-learn, LightGBM, NumPy, SciPy (FFT) || Frontend  React 19, Vite, Recharts || Data  PostgreSQL, Redis, SQLite fallback || Deploy  Docker Compose, Nginx, Prometheus /health || Hardware  Commodity x86 server. No appliance, no GPU.
 9: Methodology
 10: Ingest → flow assembly → feature extraction → batched inference → scoring → alert. || Async queue: capture never blocks on inference. Backpressure on replay, drop-counting on a live tap. || Deterministic: seed 42, same corpus gives the same numbers on any machine.
 12: What a one-way tap costs us
 13: JA3S needs the ServerHello, which we cannot see, so we do not use it. syn_ack_ratio and byte_ratio_outbound were removed for the same reason and replaced with one-sided substitutes.

##### SLIDE 4 #####
 2: Feasibility and Viability
 4: SIH26145  ·  NTRO  ·  Caffeinated Coders
 5: RISKS, AND WHAT WE DO ABOUT EACH
 7: Risk 1.  Real diode traffic needs clearance we do not have
 8: Mitigation.  We build on the sources the statement itself names: hping3, Slowloris, dnscat2/iodine, DGArchive, Tranco. The alert schema matches NetFlow/IPFIX, so a cleared operator can point the sensor at live telemetry without code changes.
 10: Risk 2.  C2 beacon precision is 0.30, our weakest number
 11: Mitigation.  Scoring periodicity without destination context made NTP and ordinary telemetry look like beacons. Fan-in is now gated. Still the first thing we would fix with more time.
 13: Risk 3.  Accuracy drifts as traffic patterns change
 14: Mitigation.  Detectors are independent, so one can be retrained in isolation. Every metric ships beside a naive baseline, so a silently broken model is visible rather than flattering.
 16: Weaknesses we found ourselves, and fixed
 17: DGA scored AUC 1.00 on our first corpus. Domain length alone separated the classes. Rebuilt on 142,582 real domains, dropped length: CV AUC 0.9966. || DDoS fired on every SYN burst. Moved to flow rate plus source-IP entropy.
